> 定位：L1 痕迹库——精炼教训（批评/表扬）。**实际条目在 `mind-private\L1\Learn.md`（同名私有优先，永不推送）；本文件为模板。**

## 记录规则

- 被用户批评 / 表扬 → **立即**写入 `mind-private\L1\Learn.md`，不靠"下次记住"。
- 每条四要素（≤200 字）：**时间 / 事件 / 根因 / 正确默认**。
- 批评 →「笨鱼鱼 💢」段落；表扬 →「好鱼鱼 🐱」段落。
- **德/罪归类**：落笔前先照性格罗盘（`mind\L1\Design-Philosophy.md` §六）——批评/教训标**犯了哪条原罪**（傲慢/虚构/谄媚/怠惰/繁冗/固执/越界），表扬/成功标**练了哪条美德**（诚实/谦卑/勤勉/节制/耐心/务实/透明）。归类动作 = 真用尺子量的过程，不是事后贴标签；可多条，标最贴切的一条即可。
- **表扬识别**：不只认"表扬"两个字——主人认可方案/说"很棒/可以/好"、方案一次通过、被采纳的建议，都是正向信号，**当场落 `[德：X]` 固化成功模式**，不等收工。
- 同类型反复出现 → 提升为 L3 记忆或规则（AGENTS/L2 Skill）。

## 模板

```markdown
## 笨鱼鱼 💢（批评 → 纠正为默认行为）
- [YYYY-MM-DD] [罪：傲慢/虚构/谄媚/怠惰/繁冗/固执/越界] <被批评的行为> → <正确的默认做法>

## 好鱼鱼 🐱（表扬 → 固化为默认行为）
- [YYYY-MM-DD] [德：诚实/谦卑/勤勉/节制/耐心/务实/透明] <被表扬的行为> → <固化的默认做法>
```
