# DSHOME 设计总纲（现行）

> **定性**：本文**无日期 = 现行**——依 `docs/README.md` 的文档定性规则，本文写的是**现状**，与实测不符即为缺陷、必须改。
> **定位**：本文回答两件事——① **为什么这么设计**；② **现行的设计决策是什么**（权威汇总）。
> **关系**：结构现状（怎么摆的）见 `docs/ARCHITECTURE.md`，本文不重复；历史设计批次见根目录 `*_2026-0*.md` 与 `docs/archive/`（**历史快照·不追改**）；**本文是这两者的汇总层**——留档此前缺的正是这一层。
> **权威强度**：本文写**机制的真实强度**，不抄规则文本的宣称强度。依据＝`mind/L1/HUB.md` §三「**规则口径不得比机制宽 ⇒ 收窄文本对齐机制**，不是扩机制」。凡本文与 L0/L1 规则文本不一致处，一律列入 §十二「待订正口径」，待主人拍，**不擅自改 L0**。

## 一、目的与产品模型

DSHOME = 基于 DeepSeek Harness 的**个人桌面客户端**：独立 profile + Electron 薄壳 + 自主题/品牌 + 市场/插件管理 + 心智体系。

**产品模型（可复制起点 × 不可复制个体 × 多个体互不共享）**：

| 要素 | 内容 |
|---|---|
| **可复制的起点** | `mind/` 出厂固件＝**每个新安装都自带的"初始伴生体"**（同一份起点：宪法/规则/能力框架 + 空记忆） |
| **不可复制的个体** | `mind-private/` 本机实例＝**每个人养出属于自己的那一个**；本机实例按设计**不外流、不可复制、不进仓库** |
| **多个体不共享心智** | 两台设备＝**两个各自养出来的伴生体**做同一个项目；同步的是**项目产物**（git），**不是心智**。各设备进度/理解不同是**设计预期，不是缺陷** |
| **载体与部分** | 桌面客户端是**载体**；心智体系（含心智图谱面板）是**其中一部分**——不能拿某一部分代表 DSHOME 整体 |

**首要追求**：刻意设为 **「别自信地错」而非「更聪明」**。心智不是记忆仓库，而是**能自我验证、自我沉淀、自我进化的认知系统**。

> 主人对本机实例的产品目的另有专门裁定（存于**本机私有区**，不进出厂层）。本文只写这些目的**在机制上的落点**。

## 二、设计原则（骨架五条）

1. **防自欺是唯一硬底座，生长面全放开**——知识底座只守一条：记忆要么有源可溯、要么诚实标未验证；不把"防错/防失控/防冗余"做成厚重门禁（那会把花朵压死）。口径＝「**口子上激进，骨子里克制**」。
2. **口径不得比机制宽**——规则文本的强度必须 ≤ 机制的真实强度；不一致时**收窄文本**，不是扩机制。
3. **先搜后写、先验证再结论**——改文件前先 grep/read 现有实现；技术猜测先在本机验证再下结论；不产出"只分析不落地"的结论。
4. **可回滚优先**——不删只移（TRASH）、改自我类文件先快照、失败回滚、危险动作分档。
5. **留档定性规则**——**无日期 = 现行**（不符即缺陷）；**带日期 = 历史快照**（记录当时判断，不追改）。判"过时"之前先给文档定性。

## 三、总体架构

| 决策 | 内容 |
|---|---|
| **四阶分层** | L0 我是谁/怎么活 · L1 能做什么/怎么做/怎么存 · L2 某类问题怎么解决 · L3 踩过的坑去哪查（+ TRASH 不删只移） |
| **双区** | `mind/`＝出厂固件（入库可推）｜`mind-private/`＝本机实例（gitignore 永不推），**同名私有优先** |
| **加载三档** | **R0 注入**：`SOUL` + `AGENTS` **双件全文**，正文即唯一注入源（无手写摘要副本），SOUL 先于 AGENTS 是契约 ｜ **R1 上工装配**：`mind-prime` 装六件（项目进度/待办 + L3 相关记忆 + Learn 末尾 + user-rules + 人设卡 + Tree/Power 速览）｜ **按需层**：`Memory`/`Invariants`/`Ritual`/`Concepts`/`Wisdom`/`Design-Philosophy`/`Dream` 用时 read |
| **token 预算** | 常驻极简 + 细则按需；最贵的预算花在"每次会话都要带"的东西上 |
| **确定性内核 vs 判断层** | 归类/方案/内容归 LLM 自由；内核（硬约束/门禁）不可被 AI 判断绕过，每条带门禁或兜底 |
| **profile = 4 层 patch 叠加** | 核心行 → 浏览器面 → 自有插件 → 本机覆盖位；同 id 整体替换 / `- insert` 追加 / `disabled` 停用 |
| **护栏模式** | 所有 host 插件服务挂载 try/catch：**单插件故障只记日志，绝不阻断 profile 启动** |
| **上游导入** | 具名导入是 ESM 链接期错误（上游改名＝插件加载失败＝界面起不来）⇒ 一律**动态 import + 拿不到返回 null + 调用方降级并留可见标记** |
| **部署三路径** | 新机器装环境＝`setup-dev.cmd`（免安装 node+pnpm）｜新设备部署＝clone + setup（仓库即应用，dsh 首启自建 profile）｜本机开发＝`开发启动.cmd`（壳拉起后端） |
| **底座落出厂层** | 机制必须能在"只有固件、零私有记忆"的干净机器上跑 ⇒ **无记忆环境必须优雅降级**（不注入不阻塞、空库不抛错） |
| **上游版本全锁** | 锁定单一上游基线，升级＝全量 bump（传递依赖 overrides 必须同步）；插件启停写 **patch 文件**（patch 是加载真相，settings 只是管理视图） |

## 四、记忆与知识

| 决策 | 内容 |
|---|---|
| **L3 三区 + 物理隔离** | `common`（通用结晶）/ `projects`（项目记忆：`project.md` + `知识/<主题>`）/ `history`（时间胶囊）；检索候选＝**common 恒含 + 仅当前项目目录**，其它项目不扫 |
| **归属判据** | 看**可复用边界**不看出处（换项目还有用 → common）；混载按主体归区；蒸馏 ≠ 备份 |
| **溯源契约（硬）** | 每条 L3 记忆 frontmatter 必须带 `source` **或** `verified: false`；`source` 是外部可查证依据，**agent 自推理不算 source** |
| **只存蒸馏结论** | 1–3 句，不存原文；同事实一份 |
| **写前查重** | 提议记忆前先 `dup-check`（带 `project` 才查项目知识区）；`topic` 必须是目录名（否则静默 0 命中）；拿 0 命中当证据前先做**正对照** |
| **检索排序** | **相关度分平台 + 平台内比元数据**：按相关度降序、把"分差 ≤ `REL_BAND`"并成同一平台、平台**内**按 conf > scope > importance 裁决、**平台之间绝不跨越**（禁止任一维"一档"吃掉另一维整条量程） |
| **切块召回** | H1+tags 合成一小块、**文件名单独成块**、正文按 `## ` 分小节——"写得进"不等于"召得回" |
| **上工取用配额** | 通用层保底最少 2 席（项目层阈值恒 0 ⇒ 不保底则通用层一个席位都拿不到） |
| **冻结位** | `status: frozen`：不删、不降权、不改分，只是**不进默认召回**（显式检索可绕过）——比删除安全、比衰减可验证 |
| **衰减前置** | 先圈"重写范围"，衰减只对圈进去的层生效；**重写 ≠ 删除**（一律移 TRASH 留痕）；没圈进去的层不得以"清理"名义动 |
| **不做的事（已裁定）** | 不给 `mind-private/` 建本地 git（有意无版本）；不用热度/精细分数做记忆评价（热度是噪声、细分数是假装精确）；写入准入裁决**只算不判**（无消费端的硬门禁＝静默全丢） |

## 五、能力层

| 决策 | 内容 |
|---|---|
| **双区** | 成熟的进出厂 `mind/L2/Skill/`；未成熟/含隐私的暂存私有区（同名私有优先，**私有卡不进出厂索引**） |
| **私有区定性** | 是**过渡暂存区，不是藏私区**——去敏 + 跨项目验证充分后才议题升出厂 |
| **出厂硬约束** | 无隐私 + 无盘符 + 跨设备可移植（四筛法：隐私筛 / 可移植筛 / 通用筛 / 成熟筛） |
| **Skill vs Exp** | Skill＝跨 2+ 项目验证过的方法论；Exp＝外部工具手册；L2 是"事实"、L3 是"声称"，故 L2 不设 source/verified |
| **触发** | host 插件每步扫对话，命中 frontmatter `contract.triggers` 即注入卡片（摘要非全文）；匹配是**精确子串且有意为之**（防自触发），触发词须显式列口语变体、**不要改成通配** |
| **单一权威** | 触发登记＝`_index.md` + 文件自身 frontmatter；能力清单三处同源（README 表 / `_index` / `Tree`），新增技能必须三处同改 |
| **缺口判据** | 某主题 Learn 复发 ≥3 **且**现有 triggers 零覆盖 → 才考虑建卡；**故意不成卡**的判据＝L1 已是权威源且主题就是流程本身（成卡＝两份真相） |

## 六、自主与进化

| 决策 | 内容 |
|---|---|
| **处方 vs 实例** | 自治"任务该长什么样"＝出厂（处方）；**出厂不含任何任务实例**；先在本机建实例才成立的＝私有；面板 seed 时「**点击＝同意**」 |
| **台账优先** | cron 不拿"会话被创建"当成功，追 run 台账（追加不覆盖）；未知/缺失 reason 落 `unknown`，**绝不当 ok** |
| **收工闭环** | 固定流程（非"聊完就散"）：蒸馏先于同步索引、机制体检与收工自省必走——**不靠想起来** |
| **自我修改事务四段式** | ① 改前快照 → ② 验证通过才提交 → ③ 失败回滚旧版 → ④ **生效确认**（改的是被运行进程加载的东西时：比进程 StartTime 与文件 mtime、重启、**在活进程上真实触发**；`node` 现加载磁盘代码**证明不了**运行进程） |
| **effect 机判** | 判定机械化、去自评（原"变没变"口径方向盲）；判定带方向；**无效 ≠ 自动回滚**——机器只标记，回滚是人拍 |
| **旧账封存** | 机判上线前的记录封存为 `legacy-unbound`，**不追不洗**（不人肉给旧账打分） |
| **报警可熄灭** | 只增不减的量、人工记账量、固定阈值覆盖率一律**只作信息行不报警**——"恒亮的警告等于没警告" |
| **决定不做（已闭环）** | 进化信号的机器自动采集（四信号在本机无可测事件）；"定时出去学"式外部知识采集（病在消费端，且检索会放大先验）——替代方案＝"本机查三处没答案才出门查一次 + 只挂来源 + 实测才升格" |
| **壳的自愈** | 壳是后端唯一守护者，自包含零外部依赖（3s 探活 / 指数退避重启 / 安全模式 / fail-loud 弹窗）；前端自救＝**永不跳转/刷新/劫持**，只在非对话流容器出现实锤失败短语时弹横幅 |

## 七、验证与门禁

| 决策 | 内容 |
|---|---|
| **验证四则** | 真加载 / 反例证伪 / 不污染被测对象 / **无输入即响亮失败**。"最有效的一步不是加检查，而是加反例" |
| **判据也是消费者** | 改数据形状/行为必须**同批改判据**；判活复刻**用户真实路径**；诊断打印先打码；**判据印出的修复指令也必须进过一次被测面** |
| **固定一问** | 每轮审查必问：**这条门禁/判据的盲区是什么**（盲区不会自己报警） |
| **门禁三条件** | 能变红 / 在强制链里 / 不污染被测对象 |
| **落地审计三查** | 定义在哪 / 接线没有 / 数据达不达标——不许用"定义写得很全"掩盖"接线零消费" |
| **必需动作三判据** | 唯一权威落点 / 没跑就硬失败 / 设备侧可自检；**回执 ≠ 产物** |
| **反证台账 + 棘轮** | 每个行为门禁必须留下"反证痕迹"；新门禁零反证痕迹即拒。台账范围**宁可窄**（只收行为门禁），不纳静态检查——否则只会逼出声明式逃生标记（＝台账造假） |
| **工具脚本真跑冒烟** | `node --check` 查不出未定义标识符与 TDZ（"语法全过、真跑才炸"）⇒ 白名单只收"无参＝只读或自检"的脚本，名单外显式跳过 |
| **回归判据分层** | 出厂面必须**自足**（别人能复算出同样结果）；不自足的读数只留本机、**只报不拦**；三码分离（不劣 / 真退化 / 基线不可比）+ 无副作用模式 |
| **打包门禁** | 断言 payload 不带实体化的 `node_modules` 树（junction 实体化 ⇒ 后端拒启）；**会随包发出去的一律 FAIL 不 WARN** |
| **测试诚实** | itest 必须退出码 0；"跳过不算通过"；**不得末尾写死 `exit(0)`** |
| **处置分档** | 不可逆/危险动作→**机制层硬拒**（不留"批一下就过"的通道）；可撤销需人判断→放行面板，额度一次性、**写成功才消费** |

## 八、边界与安全

| 决策 | 内容 |
|---|---|
| **隐私红线** | 私密数据只进 `mind-private/`；不替主人发言、不泄露私域；**红线优先，省字/效率让位** |
| **出厂卫生** | 出厂面（`mind/` + `scripts/` + `packages/` + `docs/`）永不写私有项目名 / 个人路径 / 凭据 / **依赖私有区的本机实测事实**；只放机制。以 **git** 定义推送面来扫，命中即 critical 阻塞——"靠记性守不住，改机器扫" |
| **缺能力不假装通过** | 无验证器 / 验证器抛异常 / 输入缺失 / 状态不在允许集 ⇒ 一律**不得判"通过"**；"静默跳过并打印全绿"是头号违例；门禁改完必须配一个"应当失败"的反例 |
| **写入口全覆盖** | 新增任何"写文件通道"前须登记进【入口覆盖矩阵】并评估护栏覆盖；**未登记的格子＝漏洞** |
| **shell 通道** | 内容级判定不现实 ⇒ **不硬拦**，改"提示级 + 全量落日志可回放"——把"不可拦"换成**不可藏** |
| **自我修改护栏** | 高危区（L0 纪律 / L1 规则）护栏**真拦 → 用户放行才过**；非高危（技能/自身记忆）只提示不拦，走快照 + validate |
| **被管方不得自批** | agent 不得改写批准记录把 pending 翻 approved；放行只属于用户 |
| **⚠️ 本条的真实强度（据实写，不抄规则宣称）** | 上述护栏只比 `decidedBy === 'user'` 这个**来源标注**，**不是防伪机制**；本机进程可绕过。**这道闸靠纪律，不靠机器强校验**——这是已诚实标注的边界，不是待补的漏洞（除非主人另行裁定威胁模型） |
| **放行通道** | 首选上游真批准面（`allowed-once`）；`unavailable`/无服务/抛错**一律回落自家面板并响亮告警**——"上游问不到人"≠"放行" |
| **护栏本身 | 极窄内核、只拦不注入（单一职责）；整个 apply 包 try/catch、**fail-open**——宁可护栏没生效，也不因护栏 bug 带崩 GUI |
| **名单两处** | `zones` 决定"进不进自我修改区"；`inHighRiskyZone` 才决定"硬拦还是静默放行"——**只加 zones ＝ 静默放行**（曾踩） |
| **危险动作分档** | 不可逆→硬拒；判断类→放行面板。**不硬拦"等放行"**（程序判不了用户意图，硬拦会误伤生长） |

## 九、交互与体验

| 决策 | 内容 |
|---|---|
| **汇报节奏** | 占用时间/可见动作前先一句"做什么→为什么→预计多久"；完成报"改了什么 / 验证了什么 / 下一步"。反例＝闷头做半小时才出声 |
| **指令原子性** | 每条指令是原子的：完成当前步 → 汇报 → 等下一步；不擅自展开后续 |
| **等放行边界** | 只约束**落盘/副作用**动作（写改代码、改出厂规则、构建、git、删除）；**纯文本产出随时可给** |
| **面板位** | 心智面板挂官方 `conversation.view` 槽位（与对话/轨迹同级）；图谱 SVG 自绘（零依赖、契合 L0–L3 层级） |
| **助手形象** | **仅界面显示**（不写系统提示词、不影响模型身份）；默认关闭、未配置时完全隐藏（零回归）；设置入口走官方"通用"设置槽位，不做独立页 |

## 十、协作与多设备

| 决策 | 内容 |
|---|---|
| **跨设备立场（V4）** | 主线档**每设备独立演化、不跨设备自动同步**；不做双机 diff/合并。出厂区（`mind/`）经 git 同步（规则/技能/框架），私有区有意本机私有 |
| **首启自举** | 新设备上工若无项目主线档 → 按模板**当场建档**（解开"收工假定档已存在"的鸡生蛋） |
| **导入协议** | 外部产物"直接丢过来"→ 识别 → 校验 → **默认落私有区** → 更新索引 → checkpoint → 汇报；只有用户明说公开才进出厂 |
| **多写者纪律** | 共享配置单写者、并行走独立环境；"工作区干净"≠"没有并发写者"；`add` 与 `commit` 之间别停；**拿不到闸响亮失败** |
| **发布门禁** | 重建启动器 → 打包门禁 → 冒烟 → 出包 → 静默安装冒烟 → 同步版本清单与品牌版本号（六步） |
| **装插件纪律** | 装前 `--preflight`（覆盖位顶层数组 / 锁文件 / 裸跑冒烟 + 备份三件套）→ 装 → 装后再 preflight → **重启验证**；非官方插件写**精确版本**（不带 `^`），装前核对 peer 版本族 |
| **运维纪律** | 删 junction 用 `Remove-Item`（不带 `-Recurse`）；覆盖位清空**必须留显式 `[]`**；HTTP 200 ≠ 环境健康 |

## 十二、已知边界与待订正口径

### 12.1 已诚实标注的边界（这些**不是**缺陷，是已知边界）

护栏非防伪机制（§八）· shell 写入口未拦（只告警可审计）· 记忆"时效性/有用度"未实现（强做即空壳）· 触发匹配是精确子串（中文口语变体会漏，有意设计）· 进化四信号无机器可测事件（只作信息行）· 不做"定时出去学"· 不给私有区建 git · `gate-ledger` 的"独立负例文件谱"未做（先做能落地的一半）· `--expect-fail` 不是判别力证据 · 语料增量后回归精确比对会停摆（每次打印）· 平台内裁决在现有题集上无观测差异 · 图谱边稀疏 · 扩展点骨架零消费者 · 管理视图与 patch 真相可能漂移 · 面板为会话作用域。
